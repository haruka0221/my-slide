文学における計量分析

分析の対象：本文の語彙・文体・主題・感情から、 作品集合の規模・ジャンル・出版動向まで

文学の計量分析は1960年代に始まったわけではなく、 19世紀から語彙統計や著者推定の試みがある。 MostellerとWallaceの1964年の研究はその代表的な成果。 2000年代にはMorettiが遠読という考え方を提唱し、 個々の作品だけでなく、より広い文学史の構造を 捉える方法を論じた。 Burrows (2002) のDeltaは、 計量文体論・著者推定の発展として位置づけられる。 2010年代以降はJockersやUnderwoodらによって、 大規模コーパスを使った文学史研究が発展した。 なお、遠読は必ずしもコンピュータによる 本文分析だけを意味しない。 作品数や出版年などの書誌メタデータを使って 文学史を広く捉えることもできる。 今回のOpen Libraryの実習は、こちらの方向につながる。

最近の動向：DH2026（大田、2026年7月）

文学研究にもともとある「数える」場面


作品を取り巻く歴史的な位置づけについての問い


  • どのように評価されてきたか
  • いつ注目され、いつ忘れられたか
  • どの程度出版・流通してきたか
  • どのように正典化・再評価されてきたか

評価を測る：代理指標

「どれくらい評価されてきたか」は直接には測れないため、代わりの指標を数える

指標何を反映しうるか取得元の例
出版点数・版数流通Open Library、NDLサーチ、WorldCat
図書館の所蔵数流通・保存WorldCat、HathiTrust、British Library
論文での言及数学術的な注目JSTOR、OpenAlex
シラバス・教科書への採用教育Open Syllabus
翻訳の数国際的な流通Index Translationum、各国の書誌
読者の評価・書評読者受容Goodreads

多くは公開データベースから取得できる。ただし指標ごとに「何をひとつと数えているか」が異なる

何を「ひとつ」と数えるか：作品（Work）と版（Edition）

Open Library の Work（OL38663W）の下には 553件の Edition（2026年10月15日時点）

FRBR の4段：IFLA, Functional Requirements for Bibliographic Records (1998)
論文の言及やシラバスは「作品」を単位に数えられる。一方、出版や図書館の記録は、具体的な版（Penguin、Norton、岩波文庫など）として残っている。今日はこの版を Edition として扱い、原文か翻訳か（Expression）は区別せずに、同じ作品の版としてまとめて数える。版を作品ごとにまとめた「版数」を作品の指標として使う。

実習

夏目漱石『吾輩は猫である』（OL1174971W、47 editions、初出 1905）を例に

Edition の著者欄に翻訳者（Aiko Ito, Graeme Wilson など）が並ぶことを見せる。翻訳（Expression）が Edition に畳み込まれている例。同タイトルの別 Work（OL44405220W, OL43944589W）もある→補遺A1。

実習のあとに

  • ダンプファイルでの大量検索
    openlibrary.org/developers/dumps
    例：ol_dump_editions_latest.txt.gz（大きな圧縮ファイル）
  • API での自動取得
    openlibrary.org/developers/api
  • 自分の PC で作業するには、まず「ターミナル」を開く
    • Windows：PowerShell（ファイルを置いたフォルダを開き、アドレス欄に powershell と入力すると、そのフォルダで起動）
    • Mac：アプリケーション › ユーティリティ › ターミナル

AI を使うときの二つの使い方

機械的に決められること

反復できるコードの生成、データベースや GitHub の管理ツールの使い方、機器・プラットフォームの操作方法

人間の言葉で質問し、AI がソースを確認して説明する。人間は、間違っていないか、ちゃんと調べたか、回答に矛盾がないかを、やり取りしながら判断する

AI で推測すること

大規模データの照合にともなう、人間の判断の代わり（例：同じ作品か、同じ版か）

判断材料を適切に用意し、照合の精度を数値で確かめる
